# 🗜️ Zypher – Next-gen Secure Archive Tool

**Zypher** — это быстрый, безопасный и современный архиватор с графическим интерфейсом, созданный на Rust.  
Он поддерживает сжатие, шифрование, проверку целостности и самораспаковывающиеся архивы.


## ✨ Возможности

- **Алгоритмы сжатия** – Zstd, LZ4, Brotli с настраиваемым уровнем.
- **Надёжное шифрование** – ChaCha20‑Poly1305 + Argon2 для мастер-ключа.
- **Полная конфиденциальность** – даже имена файлов скрыты без пароля.
- **Графический интерфейс** – drag‑and‑drop, тёмная тема, прогресс‑бары, сохранение настроек.
- **Самораспаковывающиеся архивы (SFX)** – можно запустить как обычный исполняемый файл.
- **Проверка целостности** – каждый файл хешируется Blake3 и верифицируется при распаковке.
- **Дозапись в архив** – добавление файлов без полной переупаковки.
- **Многопоточность** – сжатие и шифрование используют все ядра CPU.
- **Кроссплатформенность** – Linux, Windows, macOS.


### Сборка из исходников
```bash
git clone https://github.com/yourname/zypher.git
cd zypher
cargo build --release
```

#CLI
```bash
# Создать архив
zypher pack -o archive.arc file1.txt file2.jpg -p secret

# Добавить файлы
zypher append archive.arc newfile.pdf -p secret

# Просмотреть список файлов
zypher list archive.arc -p secret

# Извлечь всё
zypher unpack archive.arc -o ./out -p secret

# Проверить целостность
zypher verify archive.arc -p secret

# Создать самораспаковывающийся архив
zypher sfx archive.arc -o setup.sfx
```

🧩 Детали формата

|Компонент| Описание|
|-------|-------|
|Магия| ZYPR (4 байта)
|Версия|  2 (u16)
|Флаги архива|  бит 0 – зашифрован
|Файловые блоки|  сжатое + зашифрованное содержимое с обёрнутым ключом
|Индекс|  Central Directory (имя, смещение, размеры, хеш, метод сжатия, флаги)
|Footer|  смещение индекса, размер, nonce для расшифровки индекса

При включённом шифровании индекс также шифруется мастер-ключом, поэтому без пароля невозможно узнать даже имена файлов.
